# QR Code Generator

## 📝 Overview

**QR Code Generator** is a web application built using **React.js** that allows users to generate QR codes from any text or URL. The app provides an easy and intuitive way to create QR codes, which can be scanned by smartphones and other devices to quickly access information.

With its clean interface and instant results, **QR Code Generator** is perfect for those who need a quick way to create QR codes for websites, links, or any other textual information.

🔗 [Live Demo](https://astr1cs.github.io/qr-code-generator/)

## 🚀 Features

- **Generate QR Codes**: Enter any text or URL to generate a QR code.
- **Instant Preview**: The QR code is instantly displayed as soon as you input your text or URL.
- **Download Option**: Easily download the generated QR code as an image.
- **Simple Interface**: A clean and intuitive design makes it easy for users to generate QR codes without any hassle.
- **Responsive Design**: The app works perfectly on both desktop and mobile devices, ensuring a great user experience across all screen sizes.

## 🛠️ Technologies Used

- **React.js**: A JavaScript library for building dynamic user interfaces.
- **CSS**: Custom styles for a simple, responsive design.
- **HTML**: For structuring the web pages.
- **QR Code Generation Library**: Used for creating QR codes from user input.
